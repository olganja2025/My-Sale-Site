# ALSTER Design System

Эталонные страницы: главная (`index.html`) и «Отдел продаж с нуля» (`sales-department/index.html`). Новые элементы сначала сопоставляются с существующими компонентами этих страниц. Новый визуальный паттерн создаётся только при отсутствии подходящего аналога.

## Постоянные правила

- Lime используется дозированно как акцент, а не как основной фон последовательных секций.
- Утверждённые тексты не переписываются без прямого указания.
- Длинное тире `—`, декоративные стрелки `→`, `←`, `↗` и аналогичные символы в текстах и CTA не используются.
- Кавычки в обычном русском тексте: `«...»`. Буква `ё` сохраняется.
- Рукописная заметка всегда связана с конкретным смыслом, короткая и наклонена влево.
- Переход на смежную услугу использует один компонент: вопрос или описание ситуации плюс название услуги, без стрелки.
- Offset-тень применяется только к смысловым акцентам.
- На mobile высота карточек определяется содержимым. Горизонтальный скролл страницы запрещён.

### Типографика

- Основной шрифт: `Manrope, system-ui, sans-serif`.
- Рукописный шрифт: `Caveat, cursive`, начертание `600`.
- Общий `line-height` страницы: `1.55`.
- Заголовки: `line-height: 1.08`, `letter-spacing: -.045em`.
- Service H1: `clamp(48px, 5.6vw, 76px)`, mobile `clamp(37px, 11vw, 48px)`, `line-height: 1.04`.
- Главный H1: `clamp(54px, 5vw, 72px)`, `line-height: 1`; mobile `clamp(43px, 13.2vw, 58px)`.
- Service H2: `clamp(34px, 4vw, 54px)`; mobile `clamp(29px, 9vw, 38px)`.
- Главный H2: `clamp(42px, 5vw, 68px)`.
- H3 базовый: `24px`; карточки главной: `clamp(25px, 2.2vw, 34px)`.
- Lead service: `20px / 1.55`; mobile `17px`. Lead главной: `21px / 1.5`.
- Eyebrow: `12px`, `800`, uppercase, `letter-spacing: .14em`.
- Основной расширенный текст: `18px / 1.65`; текст карточек обычно `14px / 1.5–1.6`.
- CTA: `800`, минимальная высота `52px`, радиус `999px`.

### Сетка и отступы

- Контейнер: `1180px`, desktop-поля `22px` с каждой стороны.
- Mobile-поля: `14px` с каждой стороны.
- Service-секция: `92px 0`; mobile `54px 0`.
- Главные компактные секции: `92px 0`; mobile `68px 0`.
- Отступ заголовочной группы service: `34px`; mobile `22px`.
- Базовые gaps карточек: `16–18px`.
- Базовый радиус: `28px`; общие service-карточки: `22px`.
- Внутренний padding крупных карточек главной: `30–32px`; service-карточек: обычно `18–24px`.

### Тени, движение и breakpoints

- Общая мягкая тень: `0 22px 60px rgba(21,37,31,.09)`.
- Акцентная offset-тень эталонных элементов: обычно `9px 9px 0` с lime-смешением.
- Hover кнопки главной: `translateY(-2px)`, `250ms`.
- Hover карточки: лёгкий подъём; общий базовый переход `200ms`, на главной `translateY(-7px)`.
- Reveal: начальное `opacity: 0; transform: translateY(18px)`; переход `opacity .65s ease, transform .65s ease`.
- Основные breakpoints: `980px`, `680px` и `640px`. Контрольная mobile-ширина: `390px`.

### Рукописная заметка

- Фон: `#efede5`, `#e8e9e2` или согласованный светлый вариант на сетке `18px × 18px`.
- Рамка: нейтральная или lime с низкой прозрачностью.
- Радиус: `10–14px`.
- Шрифт: `Caveat`, `20–22px`, `600`, `line-height: 1.08`.
- Канонический наклон: `rotate(-1deg)`.
- Тень: около `0 10–12px 22–25px rgba(21,37,31,.10–.14)`.

### Переход на смежную услугу

- Классы: `.service-crosslink.system-related-service`.
- Рамка: `1px solid var(--line)`.
- Радиус: `16px`.
- Padding: `20px 22px`; mobile `14px 15px`.
- Вопрос: `15px`, `800`.
- Название услуги: компактная pill-кнопка, минимум `44px`, padding `0 18px`, радиус `999px`.
- Hover: фон и рамка `var(--accent)`.
- Mobile: одна колонка, ссылка на всю доступную ширину, высота по содержимому.

## Зафиксированные расхождения эталонов

- Главная намеренно использует более крупные H1/H2 и более выраженный hover карточек, чем service-страницы.
- Высота header: главная `78px`, общие service-страницы `84px`; mobile соответственно около `70px` и `76px`.
- Рукописные заметки в поздних корректирующих стилях используют угол от `-0.8deg` до `-1.2deg`; каноническое значение для новых и унифицируемых элементов: `-1deg`.
- В старых слоях CSS остаются прежние значения палитры и радиусов, но итоговые утверждённые значения задаёт `unified-design.css` или последний корректирующий файл страницы.
- На главной часть карточек имеет смысловую асимметрию и offset-тень; service-страницы в основном используют спокойные карточки без теней.

Расхождения не исправляются массово без отдельной задачи: документ задаёт правила для новых точечных изменений.
